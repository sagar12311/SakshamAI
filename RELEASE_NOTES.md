# Public beta release notes

## 0.1.0-public-beta

- Clean source snapshot for public release; prior private Git history is not
  included.
- Local state, recordings, logs, environments, cached packages, generated
  builds, and model binaries are excluded.
- Privileged automation and hands-free capabilities are disabled by default in
  the public configuration.
- This release is intended for self-hosted evaluation and testing.
