# Contributing to Saksham

Discuss substantial changes in an issue before implementation, keep pull
requests narrowly scoped, and include tests for changed behavior.

- Never commit `.env` files, tokens, recordings, local databases, model files,
  logs, or generated build output.
- Keep privileged functionality disabled by default and preserve confirmation
  gates for destructive actions.
- Do not add public-network defaults for local services.
- Run the backend and frontend test suites plus `tools/release-check.sh` before
  submitting a release-oriented change.

By contributing, you agree that your contributions are licensed under the
Apache License 2.0.
